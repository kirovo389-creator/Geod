Обновления

Проверка версии…
Frilance автоматически проверяет новые версии. Установка APK подтверждается Android.
Сборки до v1.0.25 могли иметь другую подпись. Для перехода со старой версии потребуется один раз удалить её и установить свежий APK; локальные данные при удалении сотрутся. Подпись новых сборок сохраняется.

Правила симулятора

• Начальный баланс — $5,00.
• Пополнений, бонусов и ежедневных наград нет.
• Сделки виртуальные, цена берётся из публичных котировок.
• После банкротства прогресс не восстанавливается внутри игры. Для новой игры нужно очистить данные Frilance в настройках Android.
