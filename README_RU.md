# Telegram Read-Only

MCP-сервер для чтения Telegram: список диалогов, последние сообщения, поиск и проверка состояния сессии.

## Быстрый старт из ZIP

1. Распакуй архив в отдельную папку.
2. В корне папки найди `session.txt` и вставь внутрь **строку Telethon StringSession**. Не обычный экспорт чатов.
3. Установи Python и зависимости: `pip install -r requirements.txt`.
4. Укажи `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в окружении.
5. Запусти `python server/main.py` через совместимый MCP-хост. Инструмент `session_status` проверяет авторизацию.

Переменную `TELEGRAM_SESSION_TXT` можно задать, чтобы использовать другой путь к файлу. Для SQLite-сессии Telethon укажи `TELEGRAM_SESSION_PATH` и убери/переименуй `session.txt`.

## Безопасность и ограничения

- **Не загружай заполненный `session.txt` в GitHub, чаты или публичные архивы.** Заполняй его только после скачивания ZIP на своём устройстве.
- Если сессия когда-либо попадала в открытый доступ, отзови её в Telegram → Настройки → Устройства и создай новую.
- Сервер только читает: не отправляет, не редактирует и не удаляет сообщения.
- Это MCP stdio-сервер, не постоянный облачный сервер. Нужен совместимый хост с Python; один ZIP сам по себе не подключает Telegram к ChatGPT Android.
