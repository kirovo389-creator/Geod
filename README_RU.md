# Telegram Read-Only

MCP-сервер для чтения Telegram: список диалогов, последние сообщения, поиск и проверка состояния сессии.

## Вход через Telethon-сессию (.txt)

1. На устройстве, где запускается MCP-сервер, создай папку `~/.telegram-readonly/`.
2. Положи туда файл `session.txt`. Внутри должна быть **строка Telethon StringSession**, а не обычный экспорт Telegram.
3. Задай переменные окружения `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Путь к файлу можно переопределить через `TELEGRAM_SESSION_TXT`; по умолчанию используется `~/.telegram-readonly/session.txt`.
4. Запусти сервер. Инструмент `session_status` проверит, авторизована ли сессия, не раскрывая её содержимое.

Если у тебя не StringSession, а SQLite-файл Telethon, укажи путь в `TELEGRAM_SESSION_PATH` и не создавай `session.txt`.

**Не вставляй строку сессии в чат и не коммить её в GitHub.** Она даёт доступ к аккаунту. Храни её только на устройстве, где запускается сервер; отозвать доступ можно в Telegram в разделе устройств.

## Ограничения

Сервер только читает: не отправляет, не редактирует и не удаляет сообщения. Он использует MCP stdio и требует совместимого хоста с Python. GitHub Actions не является постоянным сервером и не подключает этот плагин автоматически к ChatGPT Android.
