# Фотик для Android

Отдельный Android-проект внутри репозитория Geod. Он не заменяет существующий Godot-проект.

## Возможности

- Видимое превью камеры на главном экране.
- Запуск и остановка видеозаписи кнопкой «Включить».
- При старте громкость мультимедиа устанавливается на максимум, но системные кнопки громкости остаются доступными.
- Пользователь выбирает аудиофайл через системный выбор файлов; воспроизведение зациклено на время активного режима.
- Видео сохраняется в системную медиатеку в Movies/Fotik.
- После записи пользователь может открыть системное меню «Поделиться» и самостоятельно выбрать Telegram или другое приложение.
- Если приложение уходит с переднего плана, активная запись останавливается.
- Сетевого разрешения в приложении нет; видео не загружается автоматически.

## Сборка

Требуется JDK 17, Android SDK Platform 35 и Gradle 8.9.

Из корня репозитория:

```sh
gradle --no-daemon -p fotik-android testDebugUnitTest assembleDebug
```

APK появится по пути fotik-android/app/build/outputs/apk/debug/app-debug.apk. GitHub Actions также прикрепляет APK к артефактам сборки и публикует его в GitHub Releases.

## Разрешения

Камера используется только для видимой записи. Разрешение микрофона необязательно для видео, но требуется для аудиодорожки с микрофона. Приложение не скрывает свой значок и не пытается закрывать другие приложения.
