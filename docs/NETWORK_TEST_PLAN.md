# Локальный кооператив: тест-план

## Сеть
1. Подключить два Android-устройства к одной Wi-Fi сети без изоляции клиентов.
2. На устройстве A нажать «Создать комнату».
3. На устройстве B указать LAN IPv4 устройства A и подключиться.
4. Проверить статус 2/2, появление второго персонажа и плавность позиции.
5. Хост закрывает приложение: клиент должен получить уведомление об отключении.
6. Проверить повторное подключение после перезапуска хоста.

Порт: UDP 24777. Автоматическое обнаружение комнат не реализовано; используется ручной ввод IP.

## Авторитетность состояния
1. Оба игрока пытаются одновременно убрать одну и ту же задачу: задача должна засчитаться один раз.
2. Оба пытаются взять один и тот же предмет: предмет получает только один владелец.
3. Клиент запрашивает загрузку крупного объекта, находясь далеко от машины: запрос должен быть отклонён сервером.
4. Проверить, что удалённая позиция ограничена по допустимому перемещению и клиент не определяет стоимость награды.
5. Проверить общую фазу миссии и одинаковый чек-лист у обоих игроков.

## Ограничения проверки
CI проверяет загрузку проекта, скрипты, экспорт и unit-проверки состояния. Фактическая игра на двух Android-устройствах, задержка Wi-Fi, переход приложения в фон и тест нагрева должны быть проверены на реальных устройствах.
