# AETHER: Осколки неба

3D-приключение для Android на **Godot 4.5.2 / GDScript**.

## Что есть в проекте
- Парящий остров, каменные руины, колонны, деревья и восемь собираемых кристаллов.
- Стартовое меню, счётчик найденных осколков и кнопка подбора.
- Android: движение слева, обзор свайпом справа, кнопки прыжка и подбора.
- ПК: WASD/стрелки, Space для прыжка, удержание левой кнопки мыши для обзора.
- Landscape orientation.

## Рендеринг и совместимость
Проект принудительно использует **Compatibility renderer (OpenGL)** для обычного Android OpenGL ES, а не Vulkan. Для повышения стабильности отключены тени и MSAA, удалены динамические OmniLight3D возле кристаллов, не используется процедурное небо, камера создаётся до первого отображённого кадра. Кристаллы подсвечиваются материалом без отдельных источников света.

Это снижает графическую нагрузку и уменьшает число потенциально проблемных эффектов, но фактический запуск на Galaxy A51 всё равно необходимо проверить на самом устройстве.

## Сборка APK
GitHub Actions использует Godot 4.5.2 и соответствующие Android export templates. После успешной сборки APK доступен в артефакте **AETHER-Android-APK** и в разделе Releases. Workflow запускается при push в `main` или вручную через Actions.

Тестовая debug-сборка предназначена для установки и проверки, не для публикации в Google Play.
